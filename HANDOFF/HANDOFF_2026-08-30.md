## Stolperfalle Shopify-Admin über den Browser des Inhabers (2026-08-31)

Wenn beim Aufruf von admin.shopify.com jedes Mal „Choose an account" erscheint
(zwei Konten im Browser), hat der Admin keine gültige Session: die Seite rendert,
aber jede Interaktion (Menü, Modal, Tippen) friert den Tab minutenlang ein und
XHRs liefern 403. Lösung: Inhaber loggt sich einmal frisch als Nisar Derbaj ein
(accounts.shopify.com/store-login) — danach läuft alles normal. Die Formular-
felder des Admins liegen in Shadow-DOM (querySelector findet sie nicht; für
JS-Zugriff shadowRoot rekursiv durchlaufen). Produktbild ohne Datei-Dialog
(DataTransfer/Drop auf das Input funktioniert NICHT): Bild irgendwo per HTTPS
hosten (z. B. im Repo unter `configurator/Swatches/Product renders/`, wird von
Railway ausgeliefert) → im Produkt „Select existing" → „Add media" ▾ →
„Add media from URL" → URL einfügen → Add file → Done → Save.
